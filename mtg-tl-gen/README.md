# mtg-tl-gen

Rust code generator for [Type Language] definitions. It takes the output of `mtg-tl-parser` and
writes the types, enums and functions that `mtg-tl-types` includes at build time.

Telegram documentation this crate implements:

- [Type Language]
- [Binary Data Serialization](https://core.telegram.org/mtproto/serialize)

[Type Language]: https://core.telegram.org/mtproto/TL
